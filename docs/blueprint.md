# **App Name**: PortfolYOU

## Core Features:

- Hero Section: Clean and responsive hero section to make a strong first impression. Includes name, tagline, short intro, and a call-to-action button.
- About Section: Detailed 'About Me' section showcasing a professional profile photo, bio, and skills.
- Projects Section: Dynamic project cards that expand into detailed case study pages when clicked. Focus on visual presentation and clear project descriptions.
- Contact Section: Interactive contact form that submits user information to a pre-configured email address. Includes social media links.
- Sticky Navbar: Sticky navigation bar with smooth scrolling to improve user experience and site navigation.
- AI Portfolio Description: AI-powered tool to generate personalized portfolio descriptions based on user's skills and experiences. Includes suggestions for improvements.

## Style Guidelines:

- Primary color: Dark indigo (#4B0082) to convey sophistication and creativity.
- Background color: Very dark gray (#222222) to provide a sleek, modern backdrop.
- Accent color: Vibrant fuchsia (#FF00FF) to highlight key interactive elements and calls to action.
- Body font: 'Inter', a grotesque-style sans-serif with a modern and neutral look.
- Headline font: 'Space Grotesk', a proportional sans-serif with a techy feel, paired with Inter.
- Use modern, minimalist icons to represent different skills and services.
- Grid-based layouts with balanced whitespace to create a clean and structured look.
- Subtle transitions and animations to enhance user engagement without overwhelming the design.
